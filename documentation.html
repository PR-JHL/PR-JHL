🛠️ SolidWorks AI Script Assistant

使用自然语言驱动SolidWorks智能建模

📖 简介

SolidWorks AI Script Assistant 是一款创新的SolidWorks插件，利用人工智能技术将您的自然语言描述转换为可执行的SolidWorks API脚本。无需深入了解编程，只需用日常语言描述您的设计意图，AI就能帮您生成精准的建模脚本。

💡 核心优势： 通过云端AI API实现智能脚本生成，支持将常用操作保存为可复用的Skills，大幅提升建模效率。

复用操作
  1. 配置API密钥
    在插件界面输入您的OpenAI API密钥，选择合适的模型（推荐GPT-4）
  2. 描述建模需求
    使用自然语言描述您想要在SolidWorks中执行的操作，如"创建一个100mm的立方体"
  3. AI生成脚本
    点击生成按钮，AI将分析您的描述并生成对应的SolidWorks API C#脚本
  4. 预览和执行
    在执行前预览生成的脚本，确认无误后点击执行，脚本将在SolidWorks中运行
  5. 保存为Skill（可选）
    对于常用的操作，可以将其保存为Skill，下次直接调用，无需重新生成

🚀 快速开始

1. 环境要求

组件 要求
操作系统 Windows 10/11 (64位)
开发工具 Visual Studio 2022 或更高版本
.NET Framework .NET Framework 4.8
SolidWorks SolidWorks 2022 或更高版本
API服务 OpenAI API 密钥

2. 安装步骤

步骤 1: 获取SolidWorks API程序集

从SolidWorks安装目录复制以下文件到项目的 lib 文件夹：

SolidWorks.Interop.sldworks.dll SolidWorks.Interop.swconst.dll SolidWorks.Interop.swdocumentmgr.dll

通常位于: C:\Program Files\SOLIDWORKS Corp\SOLIDWORKS\api\redist\

步骤 2: 编译项目

1. 使用Visual Studio打开 SolidWorksNLPPlugin.sln 2. 选择 x64 平台配置 3. 选择 Release 配置 4. 点击「生成」→「生成解决方案」

步骤 3: 注册插件

以管理员身份运行命令提示符，导航到编译输出目录，执行： regasm /codebase /tlb:SolidWorksNLPPlugin.tlb SolidWorksNLPPlugin.dll

步骤 4: 启用插件

1. 启动SolidWorks 2. 打开「工具」→「插件」 3. 找到「SolidWorks AI Script Assistant」并勾选 4. 点击「确定」

💡 使用示例

示例1: 创建基础几何体

输入描述

创建一个100mm的立方体

AI生成的脚本

// 创建100mm的立方体 var partDoc = swApp.ActiveDoc as PartDoc; partDoc.InsertSketch2(true); var sketchManager = partDoc.SketchManager; sketchManager.InsertRectangle(0, 0, 0, 0.1, 0.1, 0); partDoc.InsertSketch2(true); var featureManager = partDoc.FeatureManager; featureManager.FeatureExtrusion2(true, false, false, 0, 0, 0.1, 0.01, 0.01, false, false, false, false, 0, 0, false, false, true, true, true, 0, 0, false);

输入描述

示例3: 复杂建模操作

输入描述

创建一个新零件，在前视基准面上画一个边长100mm的正方形草图，然后拉伸50mm

AI生成的脚本

// 创建新零件，绘制正方形草图并拉伸 var partTemplate = swApp.GetUserPreferenceStringValue((int)swUserPreferenceStringValue_e.swDefaultTemplatePart); var newDoc = swApp.NewDocument(partTemplate, 0, 0, 0); // 选择前视基准面 var selMgr = newDoc.SelectionManager; newDoc.Extension.SelectByID2("Front", "PLANE", 0, 0, 0, false, 0, null, 0); // 创建草图 var sketchManager = newDoc.SketchManager; newDoc.InsertSketch2(true); // 绘制正方形 double size = 0.1; // 100mm sketchManager.CreateLine(-size/2, -size/2, 0, size/2, -size/2, 0); sketchManager.CreateLine(size/2, -size/2, 0, size/2, size/2, 0); sketchManager.CreateLine(size/2, size/2, 0, -size/2, size/2, 0); sketchManager.CreateLine(-size/2, size/2, 0, -size/2, -size/2, 0); // 拉伸 newDoc.InsertSketch2(true); var featureManager = newDoc.FeatureManager; featureManager.FeatureExtrusion2(true, false, false, 0, 0, 0.05, 0.01, 0.01, false, false, false, false, 0, 0, false, false, true, true, true, 0, 0, false);

🎯 Skill管理

Skill是插件的核心功能之一，允许您将常用的建模操作保存为可复用的模板，避免重复生成相似脚本。

保存Skill

  1. 使用AI生成一个满意的脚本
  2. 点击「Save as Skill」按钮
  3. 在弹出的对话框中输入Skill名称和描述
  4. 点击「Save」保存

使用Skill

  1. 切换到「Skills」标签页
  2. 在列表中找到需要的Skill
  3. 双击或点击「Use Selected Skill」加载
  4. 脚本将自动填充到脚本区域
  5. 点击「Execute Script」执行

管理Skill

💡 提示： Skill文件保存在 %APPDATA%\SolidWorksNLPPlugin\Skills\ 目录，以JSON格式存储，可以手动备份或分享。

❓ 常见问题

Q: 插件没有出现在SolidWorks中？

A: 请确认以下几点：

  • 使用了x64平台编译Release版本
  • 正确使用regasm注册了dll（需要管理员权限）
  • SolidWorks版本是2022或更高
  • 检查SolidWorks「工具」→「插件」列表

Q: API调用失败？

A: 可能的原因和解决方案：

  • API密钥错误或已过期 → 检查并更新API密钥
  • 网络连接问题 → 确保网络畅通
  • API额度用完 → 检查账户余额和限额
  • API URL配置错误 → 确认端点地址正确

Q: 脚本执行出错？

A: 常见原因和解决方案：

  • AI生成的脚本有语法错误 → 尝试重新生成
  • 前置条件不满足 → 确保有激活的零件文档
  • SolidWorks API调用方式不正确 → 手动调整脚本
  • 模型文档状态异常 → 新建或打开零件文档

Q: 如何使用其他AI模型？

A: 支持使用任何兼容OpenAI API格式的服务，只需在配置界面修改API URL和模型名称即可。

Q: Skill文件在哪里？

A: 保存在用户应用数据目录：%APPDATA%\SolidWorksNLPPlugin\Skills\

🛡️ 安全建议

⚠️ 重要安全提示：
  • 脚本验证：执行前务必预览生成的脚本，确认操作符合预期
  • 备份数据：重要操作前建议备份SolidWorks文件
  • 测试环境：新脚本建议先在测试环境中验证
  • API安全：API密钥仅存储在内存，不持久化
  • 权限控制：使用具有适当权限的账户运行插件
